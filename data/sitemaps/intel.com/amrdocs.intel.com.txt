<section id="autonomous-mobile-robot">
<h1>Autonomous Mobile Robot<a class="headerlink" href="#autonomous-mobile-robot" title="Link to this heading">#</a></h1>
<p>The Autonomous Mobile Robot provides software packages and pre-validated hardware modules for sensor data ingestion, classification, environment modeling, action planning, action control. Built on the (ROS 2 Humble) robot operating system, it also features reference algorithms and working examples.</p>
<p>Beyond autonomous mobility, this package demonstrates map building and Simultaneous Localization And Mapping (SLAM) loop closure functionality. It utilizes an open source version of visual SLAM with input from an Intel® RealSense™ camera. Optionally, the package allows you to run Light Detection and Ranging (LiDAR) based SLAM and compare those results with visual SLAM results on accuracy and performance indicators. Additionally, it detects and highlights the objects on the map. Depending on the platform that is used, workloads are executed on an integrated GPU or on Intel® CPU.</p>
<p>The Autonomous Mobile Robot addresses industrial, manufacturing, consumer market, and smart cities use cases, facilitating data collection, storage, and analytics across various nodes on the factory floor.
Develop, build, and deploy end-to-end mobile robot applications with this purpose-built, open, and modular software development kit that includes libraries, middleware, and sample applications based on the open source ROS 2 Humble robot operating system.</p>
<section id="architecture">
<h2>Architecture<a class="headerlink" href="#architecture" title="Link to this heading">#</a></h2>
<p>The Autonomous Mobile Robot collection groups its components into <strong>sensing</strong>, <strong>perception</strong>, <strong>SLAM &amp; mapping</strong>, <strong>navigation</strong>, and the <strong>application</strong> layer — all on ROS 2 and accelerated on Intel® Core™ / Core™ Ultra. Intel-optimized components (marked ★) sit alongside upstream ROS 2 packages such as Nav2.</p>
<p><img alt="Autonomous Mobile Robot application component grouping" src="../../../_images/AMR-Application-Grouping.png" /></p>
<p>The reference <code class="docutils literal notranslate"><span class="pre">Wandering</span></code> application ties these together end-to-end. Sensors feed perception and SLAM; the Wandering application — two Intel ROS 2 nodes, <code class="docutils literal notranslate"><span class="pre">WanderingMapper</span></code> (builds the occupancy map and picks the next unexplored frontier) and <code class="docutils literal notranslate"><span class="pre">GoalCatcher</span></code> (issues <code class="docutils literal notranslate"><span class="pre">NavigateToPose</span></code> goals) — drives exploration through Nav2, while obstacles from Object Detection, ADBScan, and GroundFloor Segmentation continuously update the Nav2 costmap. Nav2 then commands the robot base.</p>
<p><img alt="AMR reference application: Wandering plus Nav2" src="../../../_images/AMR-Reference-Application.png" /></p>
<p>For how this collection fits into the full stack, see the <a class="reference external" href="https://docs.openedgeplatform.intel.com/dev/ai-suite-robotics.html">Robotics AI Suite architecture overview</a>.</p>
